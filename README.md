# Flowboard

Tableau Kanban fluide : glisser-déposer des cartes entre colonnes, étiquettes, priorités, échéances, checklists, recherche et filtres, statistiques animées, thème clair/sombre, sauvegarde locale.

**Stack** : React 18, Vite 5, Tailwind CSS 3, dnd-kit, Framer Motion.

```bash
npm install
npm run dev
npm run build
```

Raccourcis : `N` nouvelle carte, `/` recherche, `Échap` ferme la fenêtre. Double-clic sur le titre d'une colonne pour la renommer.
